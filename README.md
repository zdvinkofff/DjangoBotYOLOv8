# DjangoBot YOLOv8 — Асинхронный бот компьютерного зрения для детектирования объектов

Высокопроизводительный сервис на базе нейросети **YOLOv8** и фреймворка **OpenVINO**, реализованный в виде Telegram-бота для распознавания, классификации и сегментации объектов на фото и видео в режиме реального времени.

Проект демонстрирует навыки интеграции тяжелых моделей машинного обучения (Deep Learning) в интерактивные пользовательские интерфейсы с оптимизацией скорости работы нейросети.

---

## 🛠 Технологический стек и архитектура

*   **Core AI / Computer Vision:** Ultralytics YOLOv8 (предобученные и кастомные веса моделей).
*   **Оптимизация нейросетей:** Intel OpenVINO Toolkit (для кратного ускорения инференса модели на CPU).
*   **Обработка медиаданных:** OpenCV, Pillow (изменение размера, отрисовка bounding boxes, масок сегментации и подписей классов).
*   **Бот-платформа:** python-telegram-bot / aiogram (асинхронная обработка входящих медиа-потоков).
*   **Веб-инфраструктура:** Элементы Django для администрирования и логирования (опционально).

---

## 🚀 Реализованный функционал и инженерные решения

1. **Real-time Object Detection:** Автоматический прием графических и видеофайлов от пользователя, прогон через сверточную нейросеть YOLOv8 и мгновенное определение объектов (люди, автомобили, техника и еще 80+ стандартных классов).
2. **Оптимизация инференса через OpenVINO:** Модель YOLOv8 конвертирована в формат OpenVINO IR (Intermediate Representation), что позволило снизить задержку обработки (latency) на стандартных серверных процессорах без потери точности.
3. **Визуализация результатов:** Написание кастомного пайплайна на OpenCV для отрисовки рамок обнаружения (Bounding Boxes), названий классов объектов и уровня уверенности нейросети (Confidence Score) поверх исходного изображения.

## 📊 Пример работы системы

### 📥 Входные данные:
Пользователь отправляет в чат фотографию оживленной улицы.

### 📤 Выходные данные:
Бот возвращает обработанное изображение, где каждый объект (пешеход, машина, светофор) обведен цветной рамкой с подписью, например: `Car: 94%`, `Person: 89%`.

## 🔧 Локальное развертывание

1. Клонировать репозиторий:
```bash
git clone https://github.com
cd DjangoBotYOLOv8
```
2. Установить зависимости (требуется Python 3.10+):
```bash
pip install ultralytics openvino-dev opencv-python python-telegram-bot
```
3. Запуск бота:
```bash
python bot.py
```
